● API Reference

Cineflex REST API

Complete reference for the Cineflex backend API. Manage movies, handle authentication, and update user profiles — all over a clean RESTful interface.

● Version v1
● Endpoints 17
● Auth JWT Bearer
Base URL
{protocol}://{host}/api/v1
🔐 Authentication — Most endpoints require a JWT bearer token. Include the header Authorization: Bearer <token> in every protected request. Obtain a token via the Login or Signup endpoints.

Create Movie
/api/v1/movies
▼
Full URL
{protocol}://{host}/api/v1/movies
🔑 Requires Authorization
Request Body — application/json
FieldTypeDescription
namestringMovie title
durationnumberDuration in minutes
descriptionstringFull movie synopsis
ratingsnumberAverage rating (e.g. 3.3)
totalRatingsnumberTotal number of ratings
releaseYearnumberYear of release
releaseDateISO 8601Full release date
genresstring[]Array of genre strings
directorsstring[]Array of director names
coverImagestringFilename of cover image
actorsstring[]Array of actor names
pricenumberPrice of the movie

Delete Me
/api/v1/user/deleteMe
▼
Full URL
{protocol}://{host}/api/v1/user/deleteMe
🔑 Requires Authorization

Deletes the currently authenticated user's account. No request body required. The user identity is determined from the JWT token.
