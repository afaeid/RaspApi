# RaspApi
For RaspAPI programme runs by HackClub

## Introduction 
This is a simple movie app API. You can filter, add, delete and update movies on the databse using the APi. Besides, authorization has been implemented here through JWT tokens. Used NodeJS 24.15.0 along with framework like express and mongoose.

## Key features
1. Used Mongodb Database
2. You can filter, Add, delete and update movies
3. You can Signup, Login here. Besides, you can also taste the reset password facility.
4. You can also update your information through user endpoint.
5. Read the full documentation at [/docs](https://rasp-api.vercel.app/docs) route

## Other security features
1. helmet()
  - Secure HTTP headers (Content-Security-Policy, X-Frame-Options, X-XSS-Protection, etc.)
  - Prevents clickjacking, MIME sniffing, and other common web vulnerabilities
2. express-rate-limit
  - Limits each IP to 1000 requests per hour
  - Returns a custom error message when the limit is exceeded
  - Protects against brute force and DDoS attacks
3. express.json({ limit: "10kb" })
  - Parses incoming JSON request bodies
  - Rejects payloads larger than 10kb, preventing large payload attacks
4. express-mongo-sanitize (sanitize())
  - Strips $ and . characters from user input
  - Prevents NoSQL injection attacks (e.g. MongoDB operator injection)
5. xss-clean (xss())
  - Sanitizes user input in body, query, and params
  - Strips or escapes malicious HTML/JS tags to prevent Cross-Site Scripting (XSS) attacks
6. hpp (HTTP Parameter Pollution)
  - Removes duplicate query parameters from req.query
  - The whitelist allows multiple values for: price, name, duration, ratings, totalRatings, releaseYear
  - Prevents parameter pollution attacks that could crash or confuse the app

## NOTE!
1. The base url is: `https://rasp-api.vercel.app/`
2. Replace `<<protocol>>` with `https` and `<<host>>` with `rasp-api.vercel.app` in the api url as described in the documentation.
3. Add  `"role": "admin"` at the body while signup to get the permission to add, update and delete movies. By default `"role":"user"` is set which possesses permission only to read the movies.
4. Email sending feature is not for production. The emails are traped by [Mailtrap](https://mailtrap.io). So, in reality, you will not get any email to your email address. Rather, the necessary message will be sent with http response.
5. The documentation is auto generated by Claude.
6. The server is running via vercel. 
7. view the source code [here](https://github.com/afaeid/RaspApi/)
